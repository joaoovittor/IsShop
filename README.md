# IS Shop

A modern front-end study project focused on building a fictional online store with a clean, modern, and responsive interface while applying JavaScript concepts learned throughout my front-end studies.

## About

IS Shop is a fictional e-commerce website created to practice HTML, CSS, and vanilla JavaScript.

The project simulates a modern online store, featuring product categories, product cards, customer reviews, a shopping cart, and a physical store section.

The main focus of the project is to combine previously learned JavaScript concepts with the new concepts acquired throughout the JavaScript module.

## About the Project

This project was built as part of my front-end learning journey while studying JavaScript.

Unlike previous exercises and smaller projects, the goal of IS Shop is to bring together the concepts learned throughout the JavaScript modules into a single application.

The project is intentionally kept at a manageable size, focusing on applying JavaScript concepts through real interface interactions rather than creating a fully developed e-commerce platform.
